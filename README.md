# 🌊 Life Below Water (SDG 14)

A university web development project focused on **United Nations Sustainable Development Goal 14: Life Below Water**. This repository showcases only the pages, components, and features that I personally researched, designed, and developed as part of a collaborative team project.

> **Note:** To respect academic integrity and the intellectual property of my teammates, files created exclusively by other contributors have been removed or replaced with placeholders. As a result, only my individual contributions are available in this repository.

## 🚀 Featured Contributions

### 🎨 Global UI Architecture

* Designed and implemented `Global.css`
* Created a glassmorphism-inspired design system
* Developed shared navigation, header, footer, and responsive layouts

### 🏠 Interactive Landing Page

* Built the `Home.html` landing page
* Developed a custom bubble animation using the HTML5 Canvas API
* Implemented scroll-reveal animations for enhanced user engagement

### ♻️ Marine Pollution Module

* Researched and authored the **"Stop the Stream"** marine pollution awareness page
* Designed and developed the complete page layout and user experience
* Created educational content aligned with SDG 14 objectives

## 🛠️ Technologies Used

* HTML5
* CSS3 (Custom Properties, Flexbox, CSS Grid)
* Vanilla JavaScript
* HTML5 Canvas API
* Intersection Observer API

## 🎯 Project Goal

The project aims to promote awareness about the conservation and sustainable use of oceans, seas, and marine resources through engaging web-based educational content aligned with **UN Sustainable Development Goal 14: Life Below Water**.

## 📌 Repository Scope

This repository contains **only my individual contributions** to the original group project. Other project sections and pages developed by team members are intentionally excluded.
